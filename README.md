# トレーニング記録

上半身／下半身を選び、種目・重量・回数・セット数を選択して記録していくためのアプリ。
ビルド不要のバニラJS（1ファイル）＋PWA。記録は端末のlocalStorageに保存される。

## 使い方

1. 上部で「上半身」か「下半身」を切り替える
2. 種目ごとに 重量・十の位・一の位・セット数 のプルダウンを選ぶ（複数種目まとめてOK）
3. 下の「◯種目を記録する」で保存
4. 同じページ下部の履歴で確認・削除・コピー、JSONで書き出し／読み込み

## 収録している種目と重量

| 部位 | 種目 | 重量 |
|---|---|---|
| 上半身 | チェストプレス | 5〜55 |
| 上半身 | ラットプルダウン | 5〜32 |
| 上半身 | シーテッドロープーリーロー | 5〜32 |
| 上半身 | インクラインフライ | 1〜5kg |
| 下半身 | ケーブルヒップエクステンション（キックバック／キックサイド） | 5〜50 |
| 下半身 | ヒップアダクター（アダクション） | 5〜62 |
| 下半身 | ヒップスラスト／ワイドスクワット／リアランジ（スミスマシン） | 片側 1.25〜60kg（1.25刻み） |
| 下半身 | マシンスクワット | 5〜65 |

回数は十の位（0〜5）と一の位（0〜9）の2列から選択（0〜59）。セット数は1〜5。

種目や上限を変えるときは `training-log.html` 冒頭の `CABLE` / `SQUAT` / `ADDUCT` / `CHEST` / `PULL` / `MENU` を編集する。

## GitHubに上げる

```bash
git init
git add .
git commit -m "training log app"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

GitHub Pages で公開する場合：リポジトリの Settings → Pages → Source を `main` / `root` に設定。
公開後のURLをiPhoneのSafariで開き、共有 → ホーム画面に追加でアプリとして使える（オフライン可）。

## ファイル

- `training-log.html` — アプリ本体（HTML/CSS/JSすべて）
- `index.html` — ルートURL用のリダイレクト（`/` を開くと本体に飛ぶ）
- `manifest.json` — PWA設定
- `sw.js` — オフライン用サービスワーカー
- `icon.svg` — アイコン
